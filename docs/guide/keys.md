# Keyboard shortcuts

On macOS, <kbd>Cmd</kbd> takes the place of <kbd>Ctrl</kbd> in these, and the menu bar lists them, with <kbd>Cmd</kbd>+<kbd>H</kbd> to hide and <kbd>Cmd</kbd>+<kbd>M</kbd> to minimize. Tooltips show the shortcut for your platform.

## App

| Key | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | New session |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>N</kbd> | New session, picking the project from the keyboard |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Collapse or open the sidebar |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | Show or hide the right panel |
| <kbd>Ctrl</kbd>+<kbd>Q</kbd> | Quit |

## Composer

| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> | Send. While a turn runs, steer it |
| <kbd>Shift</kbd>+<kbd>Enter</kbd> or <kbd>Alt</kbd>+<kbd>Enter</kbd> | New line |
| <kbd>Ctrl</kbd>+<kbd>V</kbd>, or <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> on any platform | Paste text, an image, or a copied file |
| <kbd>/</kbd> at the start, or <kbd>$</kbd> anywhere | Complete a slash command or a skill |
| <kbd>Up</kbd>, <kbd>Down</kbd>, <kbd>Tab</kbd> | Move through and complete the menu |
| <kbd>Escape</kbd> | Close the menu (it doesn't stop the turn) |
| <kbd>Backspace</kbd> in an empty box | Remove the last attachment |

## Transcript

| Key | Action |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected text |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all of the message you clicked in (a long reply is selected in parts) |

In the image viewer, <kbd>+</kbd>, <kbd>-</kbd>, <kbd>0</kbd> (fit) and <kbd>1</kbd> (full size) zoom, and <kbd>Escape</kbd> closes it.

## Terminal

The terminal uses Ghostty's keys. It takes <kbd>Tab</kbd>, and off macOS <kbd>Ctrl</kbd>+<kbd>B</kbd>, <kbd>Ctrl</kbd>+<kbd>N</kbd> and <kbd>Ctrl</kbd>+<kbd>C</kbd>, for the shell rather than the app.

| Linux and Windows | macOS | Action |
| --- | --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | <kbd>Cmd</kbd>+<kbd>T</kbd> | New terminal tab |
| <kbd>Ctrl</kbd>+<kbd>Page Down</kbd> / <kbd>Page Up</kbd> | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>]</kbd> / <kbd>[</kbd> | Next / previous tab |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>O</kbd> | <kbd>Cmd</kbd>+<kbd>D</kbd> | Split right |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> | <kbd>Cmd</kbd>+<kbd>Shift</kbd>+<kbd>D</kbd> | Split down |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> | <kbd>Cmd</kbd>+<kbd>W</kbd> | Close the pane |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+arrow | <kbd>Cmd</kbd>+<kbd>Alt</kbd>+arrow | Move to the pane that way |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | <kbd>Cmd</kbd>+<kbd>C</kbd> | Copy |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>V</kbd> | <kbd>Cmd</kbd>+<kbd>V</kbd> | Paste |
